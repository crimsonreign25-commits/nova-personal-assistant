# NOVA ULTIMATE

The `nova-ultimate` branch adds foundations for predictive intent, orchestration, Code Studio, mobile adapters, and security analysis.

Mobile capabilities require explicit platform adapters and runtime permissions. SMS, calls, contacts, files, photos, calendar access, VPN, malware removal, system changes, and deployments are not enabled automatically. Security modules provide heuristics and recommendations, not a replacement for OS antivirus or incident response.

## Setup

```bash
npm install
cp .env.example .env
npm start
```

## Branches

- `main`: NOVA v2 base
- `nova-ultimate`: advanced feature foundations

Test this branch before merging it into `main`.
